# 导演视角点评（针对 49 秒版）与处理

点评由组员转来，原文要点和我们的处理如下。

| 点评 | 处理 |
|---|---|
| 片尾霓虹多巴胺色跳戏，像潮玩 | 采纳。片尾改为深色网格 + 顶部冷白光，地面光环只用青色和琥珀色 |
| 黑底与纯白底来回切，刺眼 | 采纳。用法段已并入深色的“起身四步”；问题段改为偏暗的冷灰底；片名那一下的白闪改成很淡的青色闪 |
| “前移、上升、前倾”重复多次 | 采纳。运动段和用法段合并为一段；第 03 步副标题改为对人的好处“托住臀部和大腿，人不往前滑”（模型里有前滑量约束）。没有用“膝髋关节减负”：模型算的是最吃力关节的省力比例，不能直接说成关节减负 |
| 用法之后讲“确认人准备好了”，时间线倒退 | 采纳。传感段标题改为“起身全程，四处测力”，作为贯穿全程的安全检查 |
| 四连杆那行小字停留太短 | 采纳。提前出现、字号加大，停留超过 2 秒 |
| 床边镜头缺人体参照，“腿能转过去”要靠想象 | 采纳。地面箭头出现时，叠加半透明人形：从床上转身、腿从床尾一侧放下、坐到座板上（第一版做成了回床方向，组员指出和起身的叙事反了，已改为下床方向） |
| 呼应镜头图层厚重 | 采纳。机构外壳调暗，人物去掉黑色描边 |
| 松手时的“滴—滴”像监护仪报警 | 采纳，是我们的失误。改为低沉的电磁抱闸声（干脆的“咔哒”+ 闩锁 + 低频“咚”）；握开关时的提示音也从电子“滴”改为柔和的拨弦音 |

# 第二轮“挑刺”（针对 44 秒版）与处理

| 点评 | 判断 | 处理 |
|---|---|---|
| 座板里穿出一根青色的杆 | 对，是画面错误 | 那是髋部轨迹的立体管，人离开后没有隐藏；现在随人一起淡出 |
| 人头看起来撞到扶手横杆 | 画法问题，不是设计问题 | 头按模型画（头心在肩上方约 12 cm、半径约 8.5 cm），和横杆至少差 5 cm |
| 81 个人那一下太快 | 对 | 多停 1 拍（约 2 秒），数字从 0 计到 81，加“身高 1.50–1.75 m” |
| 传感段太挤 | 对 | 加长 1 秒；“横杆测力”标签挪开，不再压标题 |
| 四连杆那行字容易错过 | 对 | 移到标题正下方，琥珀色、加大 |
| 单侧悬臂怎么扛偏载没交代 | 对 | 结构段第一条标签改为“双导轨 + 滚珠丝杠：扛住偏载” |
| 座板看不出在前倾 | 不认可“没有前倾”：座板最大前倾约 15.6°，人离开时约 12.9° | 问题在看不清，所以加了水平参考虚线、座面线和实时读数“前倾 N°” |
| 机构过约束（像四连杆又加导轨） | 不认可：3 个转动副 + 1 个移动副，1 个自由度，一个电机就能驱动 | 结构段直接画出 3 个铰点和 1 个滑块，一行字“3 个铰点 + 1 个滑块 = 1 个自由度” |
| 下床路径交代不够 | 部分认可 | 床边镜头已有下床方向的半透明人形；更细的流程留给幻灯片 |
| 课程要求英文、要有数字 | 认可，但不想变成数据表 | 中文为主，每条字幕下一行灰色英文小字；画面里只放 3 个数字（81 种身体、轨迹误差 ≤ 8 mm、实时前倾角），其余数字留给幻灯片和答辩 |

# 第三轮（组员意见）
- 字太多：英文只留每个镜头的主标题；删掉重复的副标题（“前移、上升、前倾”“握紧才升”在第 02 步、结构段的“电机 · 失电制动”标签），片尾三句卖点换成一句。
- 没提老人：开场字幕改为“夜里，老人从床沿站起来”，片尾改为“帮老人自己，从床边站起来”。
- “一条线”不该写成字：删掉“每一次起身，都是一条线”，轨迹段的“这条路线 / 走出这条曲线”改为“座板怎么走…”“只用一条导轨 + 一根连杆”。线只在画面里出现。
- 床边镜头到“01 挪上座板”像换了场景：床边镜头里的人形改为停在床沿（不再先坐到座板上），背景在推镜时淡成深色网格，最后一帧与第 01 步第一帧机位、姿势一致，接成一个连续镜头。
