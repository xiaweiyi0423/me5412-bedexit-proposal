# 床边起身台 · 脉动版（技术向短片）

**成片：`bedexit_pulse.mp4`**（46 秒，1080p30，无旁白；中文字幕为主，每个镜头的主标题下面一行灰色英文小字，小标签不配英文；有配乐和音效）

这一版和 v3（鹤的故事）并列，作为另一种风格：不讲故事，不煽情，按产品发布会的节奏讲清楚：问题是什么、产品是什么、凭什么这样设计、人怎么用。设计过程只用画面带过，不讲推导。

只有一处“心理描写”，并在片尾呼应：
- **雨夜（0:08）**：起不来以后，冷蓝色的房间、窗外下雨。他想站起来，眼前浮现一个淡淡的“站着的自己”和一条通往那里的虚线；髋部那条青色的线只走到一半就塌下来，碎成水珠落下去，接上窗外的雨（雨也是一条条落下的线）。人低着头坐回床沿。
- **呼应（0:40）**：同一扇窗、同一张床、同一个机位，床边多了起身台。握紧开关，他站起来，髋部这次画出一条完整的线；雨停，窗外天亮。然后人和床淡出，只留起身台；镜头拉远转成 3/4 视角并缓慢旋转，深色网格背景，一束顶部冷白光打亮样机，地面每拍从起身台脚下扩散一圈光环（青色为主、每第四拍一圈琥珀色），鼓点同时回来；那条青色的起身线留在空中，片名在左上。

视觉母题是**点和线**：开场人由关节点连成，起身时髋部画出一条线；轨迹段里座板跟着大腿走、81 条线铺开、导轨和连杆从轨迹里长出来。

背后的事实（片中不讲，答辩时可用）：
- 81 个人 = 3 种身高 × 3 种体型 × 3 种起身习惯 × 3 种脚的位置；
- 每人一条线：座板贴在大腿下面随大腿转（倾角不超过 30°），座板中心走过的路；
- 设计曲线是从候选里**挑**出来的：每条都拿给 81 个人试，选最吃力的人也够用的那条（“1.50 m、先前倾、脚放得远”那位）。

- **节奏**：配乐 120 BPM，每拍 0.5 秒，镜头切换、零件落位和文字出现都对在拍点上。
- **画面**：
  - 全部由代码生成，没有用 AI 生成的画面；
  - 装置用 CAD 零件（`cad/out/mesh.json`）按真实运动学驱动；
  - 人物是扁平的标识小人，姿态来自起身模型（参考用户 1.60 m）。
- **配色**：深色段落讲结构和运动，浅色段落讲问题和用法；青色代表机构，琥珀色代表握把开关。全片只用这一套颜色，片尾也不换色（曾试过多巴胺色光晕，评审认为像潮玩、破坏医疗设备的可信感，已撤掉）。问题段用偏暗的冷灰底，避免从黑底切过去时刺眼。

“松手即停”那一拍（0:34.5），音乐整段静音约 1.5 秒，只留低沉的电磁抱闸声（“咔哒—咚”），用声音表现“稳稳停住”；不用高频提示音，避免像医院报警。

## 和设计一致的地方
- 座板前倾不超过约 15°。
- 人离开座板后，座板停在放手的位置，不会把人推下去，也不会自己回落。
- 握紧才升、松手就停。
- 传感点与幻灯片“传感与交互”一页一致。
- 设计过程的数据都来自 `model/calc_v13/seat_1dof/`（page.json、v5.json、fourbar_oneside.json），和幻灯片“机构设计”三页是同一套数字；五种机构的淘汰理由与“选机构”一页一致。
- 采用的机构有 3 个转动副 + 1 个移动副，可以看作把四连杆的一根杆换成导轨（滑块）；它不是四个铰链的四连杆。片中在结构段直接画出 3 个铰点和 1 个滑块。
- 片中只出现 3 个数字，都来自同一套模型：81 种身体（身高 1.50–1.75 m）、轨迹误差 ≤ 8 mm、起身时的实时前倾角（最大约 15.6°，人离开座板时约 12.9°）。
- 人物头部按模型画（头心在肩上方约 12 cm，半径约 8.5 cm），和扶手横杆保持至少 5 cm 间隙；上一版看起来“撞头”是画法问题，已改。

## 文件
| 路径 | 内容 |
|---|---|
| `bedexit_pulse.mp4` | 成片 |
| `styleframes.jpg` | 6 张效果图 |
| `src/pulse.html`、`src/pulse.js` | 画面（three.js + Canvas），`renderAt(t)` 逐帧绘制 |
| `src/prep_design.py` | 把设计过程数据打包成 `design.js`、`design_demo.js`（5 个示例用户的起身姿态和对应座板位置） |
| `review_gemini.md` | Gemini 对剧本的意见和我们的处理 |
| `src/render.js` | Playwright 逐帧截图 |
| `src/music.py` | 配乐和音效合成（numpy/scipy，不用采样） |
| `src/music_rain.py` | 雨夜和片尾呼应两段的声音（雨声、孤单的下行音、“叹气”般的上扬又落下的音、雨停后的大调和弦），拼进主配乐 |
| `src/music_ctx.py` | 床边镜头 3.5 秒的声音（线飞入的划空声、床合拢的和弦、线爬导轨的上行音、碰到开关的“叮”），插到 25 秒处 |
| `src/music_merge.py` | 合并后“起身四步”6.5 秒的声音（每步一个落点、握把的拨弦音、上升音、三个箭头音、电磁抱闸声） |
| `src/music_v11.py` | 46 秒版：在 16 秒处插入 1 拍和弦（81 停留），把传感段换成 4 秒，结尾鼓点减弱、雨声提前进入 |
| `review_director_notes.md` | 一份导演视角的点评和逐条处理 |
| `src/encode.sh` | 帧 + 音频 → mp4（响度 −14 LUFS） |

重新生成：
1. 在 `src/` 放好 `three.min.js`、`data.js`（由 `presentation/video/tools` 里的 3D 场景 `prep.py` 生成）和字体目录 `fonts/`（Noto Sans SC、Inter Tight、JetBrains Mono）。
2. 运行 `python3 prep_design.py`，再运行 `node render.js video 0 1380`（断点续渲：已存在的帧会跳过，改了画面要先删掉对应帧）。
3. 运行 `python3 music.py music_core42.wav`，再运行 `python3 music_rain.py music_core42.wav music.wav`（把雨夜和呼应两段音乐拼进去，得到 44.5 秒版本，存为 music_v6_445.wav），最后运行 `python3 music_ctx.py music_v6_445.wav music.wav`（插入床边镜头的 3.5 秒，得到 music_v9_49.wav），最后运行 `python3 music_merge.py music_v9_49.wav music.wav`（把运动段和用法段的声音换成合并后的四步，得到 44 秒，存为 music_v10_44.wav），最后运行 `python3 music_v11.py music_v10_44.wav music.wav`（得到 46 秒）。
4. 运行 `./encode.sh`。
