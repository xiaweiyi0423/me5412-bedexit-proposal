# 床边起身台 · 脉动版（技术向短片）

**成片：`bedexit_pulse.mp4`**（36 秒，1080p30，无旁白，有字幕、配乐和音效）

这一版和 v3（鹤的故事）并列，作为另一种风格：不讲故事，不煽情，按产品发布会的节奏讲清楚三件事：问题是什么、装置怎么动、人怎么用。

- **节奏**：配乐 120 BPM，每拍 0.5 秒，镜头切换、零件落位和文字出现都对在拍点上。
- **画面**：
  - 全部由代码生成，没有用 AI 生成的画面；
  - 装置用 CAD 零件（`cad/out/mesh.json`）按真实运动学驱动；
  - 人物是扁平的标识小人，姿态来自起身模型（参考用户 1.60 m）。
- **配色**：深色段落讲结构和运动，浅色段落讲问题和用法；青色代表机构，琥珀色代表握把开关。

| 时间 | 段落 | 内容 |
|---|---|---|
| 0:00 | 开场 | 心电图扫描；“夜里，从床沿站起来”；腿力 / 床高 / 头晕 |
| 0:04 | 问题 | 床低 → 站不起来；床高 → 脚踩不实 |
| 0:08 | 转折 | 平时，和床一样低；起身时，跟着你升起来 |
| 0:10 | 片名 | 床边起身台 / BED-EXIT SEAT |
| 0:12 | 结构 | CAD 零件按拍拼装（8 组），标注；“一个电机，一个自由度” |
| 0:18 | 运动 | 侧视：座板前移、上升、前倾，轨迹和每拍的座板残影；人站稳，座板停住 |
| 0:24 | 用法 | 01 挪上座板 · 02 握紧开关 · 03 一起起身 · 04 松手即停 |
| 0:30 | 传感 | 座下测力、横杆测力、握把开关、踏板测力 |
| 0:33 | 结尾 | 片名 + 一句话总结 |

“松手即停”那一拍（0:28.5），音乐整段静音约 1.5 秒，只留制动声，用声音表现“停”。

## 和设计一致的地方
- 座板前倾不超过约 15°。
- 人离开座板后，座板停在放手的位置，不会把人推下去，也不会自己回落。
- 握紧才升、松手就停。
- 传感点与幻灯片“传感与交互”一页一致。

## 文件
| 路径 | 内容 |
|---|---|
| `bedexit_pulse.mp4` | 成片 |
| `styleframes.jpg` | 6 张效果图 |
| `src/pulse.html`、`src/pulse.js` | 画面（three.js + Canvas），`renderAt(t)` 逐帧绘制 |
| `src/render.js` | Playwright 逐帧截图 |
| `src/music.py` | 配乐和音效合成（numpy/scipy，不用采样） |
| `src/encode.sh` | 帧 + 音频 → mp4（响度 −14 LUFS） |

重新生成：
1. 在 `src/` 放好 `three.min.js`、`data.js`（由 `presentation/video/tools` 里的 3D 场景 `prep.py` 生成）和字体目录 `fonts/`（Noto Sans SC、Inter Tight、JetBrains Mono）。
2. 运行 `node render.js video 0 1080`。
3. 运行 `python3 music.py music.wav`。
4. 运行 `./encode.sh`。
