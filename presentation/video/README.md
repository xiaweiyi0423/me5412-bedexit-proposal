老师建议做一段 AI 小视频，让大家更直观地理解问题和方案。本目录保存方案、素材和成片。

**成片 v3：`bedexit_concept_v3.mp4`**（65 秒，1080p，中文旁白、字幕、配乐和音效）

## 故事：善意的回响
许多年前，她在雪地里扶起过一只受伤的鹤；如今，鹤陪她自己站起来。

“扶起”这个动作贯穿首尾，也对应我们的设计原则：不是把人举起来，而是她做主、它跟着。

| 时间 | 镜头 | 形式 |
|---|---|---|
| 0:00 | 凌晨三点醒来 | 二维手绘（AI） |
| 0:03 | 床头柜特写：闹钟、老照片；推进照片，照片“活”过来，雪花飘落 | 漫画（AI 画格） |
| 0:08 | 低床起身失败 | 二维手绘（AI） |
| 0:14 | 片名“床边起身台”（宣纸、墨迹） | 字卡 |
| 0:17 | 钢笔速写“立”成三维卧室，装置在床边 | 三维（CAD） |
| 0:20 | 零件大拆大卸，再拼成一只丹顶鹤，低头致意后收回成起身台 | 三维（CAD 零件 1:1） |
| 0:27 | 挪上座板；握杆按键“咔哒” | 漫画 |
| 0:34 | 起身：墙上鹤影站在她身侧，随她慢慢扬颈 | 漫画 |
| 0:44 | 松手：按钮灯灭、座板停住；坐回，鹤影护持 | 漫画 |
| 0:49 | 站稳迈下，走向走廊夜灯 | 漫画 + 二维手绘 |
| 0:54 | 天亮，阳光照在老照片上 | 漫画 |
| 0:59 | 结尾卡：平时和床一样低 / 起身由她做主 / 松手就停 / 让她，自己站起来 | 字卡 |

零件和鹤的对应（`crane_mapping.json`、`crane_pose.jpg`、`crane_silhouette.jpg`）：

| 鹤的部位 | 零件 |
|---|---|
| 丹顶 | 琥珀按钮 |
| 头 | 电机 + 制动器 |
| 喙 | 倾角连杆 |
| 颈 | 斜导轨 + 丝杠 |
| 身体 | 两块侧板（压低成身形），内有坐垫和滑块板 |
| 尾 | 黑色横杆 |
| 腿 | 两根底座纵梁 |
| 一旁的“芦苇” | 扶手立柱 |

这只鹤只做旋转和平移，不改变零件尺寸。

注意事项：
- 鹤始终站在地上陪着她，不飞走、不驮她、不在她身下，避开“驾鹤西去”的联想。
- 照片用暖色，不用黑白。
- 片中不出现数据。
- AI 生成的画面都标了“AI 生成动画（概念示意）”。
- 片中没有实物样机。
- 坐回时座板只是停住接住她，不会后退或下降；只有按住“降”才往下动。
