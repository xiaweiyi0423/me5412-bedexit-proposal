# 床边起身台 · 概念短片

老师建议做一段 AI 小视频，让大家更直观地理解问题和方案。本目录保存方案、素材和成片。

**成片 v2：`bedexit_concept_v2.mp4`**（57 秒，1080p，有中文旁白、字幕、配乐和音效）。用 `tools/assemble.py tools/edit_v2.json` 可以重新合成，需要把原始素材放在脚本旁边的同名目录里。

## 当前方案（约 50 秒，详见 STORYBOARD.md 最后的“修订 6”）

故事：凌晨三点，一位奶奶要起床。她先在低床上起身失败；然后用起身台挪上座板、握杆按开关，座板托着她慢慢起身；中途她头晕松手，座板停住接住她；最后她站稳，走向走廊，天亮时安睡。

形式是二维手绘、三维和动态漫画来回切换：
- **开头和结尾**：二维手绘动画，AI 生成，在 `clips/` 里。
- **装置登场**：三维，由 CAD 网格渲染，画面里没有人。开头是钢笔速写，镜头一转“立”成三维卧室，最后再压回速写（`clips/S4_device_reveal.mp4`）。
- **操作过程**：动态漫画，分格画面在 `panels/`。
- **两条意象**：
  - 墙上的影子是年轻时的她，机构的影子是一只扬颈的仙鹤；
  - 放大镜小格里，机构线稿一帧帧化成水墨仙鹤（`mech_refs/` 是线稿，`panels/M2m–M5m` 是变形帧）。
- **基调**：全片不出现数据；神态特写放在 `panels/F_*`；配中文旁白、轻音乐和细小的音效。

## 还可以改进
- AI 视频每天只能生成 20 段。S10 走廊那段（想让人物走得更远）和 S2 正侧面收尾的补拍，要等额度恢复。
- 已知小问题：
  - 机构变仙鹤里 M3m 那一帧跳变太大，排动态时只一闪而过或略过；
  - Y4、Y5 里鹤影和真人略有重叠；
  - E1 里装置外壳和夜间各格不完全一致。

画面里所有 AI 生成的内容都会标“AI 生成动画（概念示意）”。片中没有实物样机。
