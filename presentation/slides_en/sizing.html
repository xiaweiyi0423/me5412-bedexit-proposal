APPENDIX · DRIVE SIZING

Ball screw drives, power-off brake holds; twin linear guides carry the one-sided cantilever

Screw: ≤ 664 N when rising (100 kg); hard sit-down static ≤ 2.0 kN (incl. along-seat force); stroke 331 mm

Offset load about 586 N·m: pivot 1 tapered roller pair (32006 X, 45 mm apart, SF 3.2) → carriage plate → twin guides, ≤ 5.2 kN per carriage (HGH15CA, SF 2.5); link rod ends: tension and compression only

Emergency lowering: hold “Down” on battery; if the controller also fails, pull the covered lever under the bar corner: it cuts motor power, then releases the brake; a centrifugal speed limiter on the screw keeps about 3 cm/s; release to stop

First picks (to check against maker catalogues): screw R16-10, fixed at top, free at bottom (in tension when seated); guides HGR15 ×2 + carriages HGH15CA ×4; brake 8 N·m; motor about 26 W, belt 1:3

Loads: rising = seat pushes 0.5 × body weight + 10 kg seat; static = 100 kg × 1.5 body weight, anywhere on the seat (virtual work); plot shows seat-normal force only, about 2.0 kN with along-seat force

This is our first drive sizing. A ball screw drives the carriage. The left plot is screw force: at most about 664 newtons when rising. If a 100 kilogram user sits down hard, with the force along the seat, it is about 2.0 kilonewtons. The right plot is seat tilt: never above 16 degrees. A ball screw is efficient but does not self-lock, so we add a power-off brake. It holds in normal use and when power fails. With no power, first hold “Down” to lower slowly on battery. If the controller also fails, pull the covered lever under the bar corner; you can reach it while seated. First it cuts motor power, then it releases the brake. The user’s weight lowers the seat, and a centrifugal limiter on the screw keeps the speed at about 3 centimetres per second, about 11 seconds in total. Let go and it stops. The seat is a cantilever, so the offset load gives about 586 newton-metres. This goes through pivot 1, with two tapered roller bearings 45 millimetres apart, then to twin guides with four carriages. The link has rod-end bearings, so it only sees tension and compression. Next, we check all parts against maker catalogues.
