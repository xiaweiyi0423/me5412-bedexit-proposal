3 · MECHANISM DESIGN ① HOW THE SEAT SHOULD MOVE

Path first: from 81 users' sit-to-stand motions, we set one curve for the seat

  • Why not vertical: hips move forward first, then up. A vertical seat lags the thighs: the user slides forward and may miss the seat when sitting back (11/81 pass)
  • Each user's ideal path: seat stays under the hip–thigh junction; forward tilt ≤ 15° (steeper: you slide down when sitting back)
  • One motor, one path: picked from the 18 users whose hips move forward earliest, so it keeps up with the most forward one; for others it supports further along the thigh. 80/81 pass
  • Other constraints: starts flush with the bed; rigid parts ≥ 1.5 cm from the bed; foot end open so legs can swing back onto the bed

81 users = 3 heights × 3 buttock thicknesses × 3 rising styles × 3 foot positions; 2D quasi-static. Pass = forward slide ≤ 2 cm and caught when sitting back. Design path to 0.61 m, then extended along the guide to 0.69 m (for cushion compression)

Mechanism design has three steps. Step one: how should the seat move? We used 81 simulated users: three heights, body sizes, rising styles and foot positions. For each one, we found the ideal seat path: under the hip–thigh junction, with forward tilt of 15 degrees at most; any steeper, and you slide down when sitting back. Everyone moves forward first, then up, so a vertical lift cannot keep up: only 11 pass. One motor can follow only one path. We chose the one that keeps up with the most forward user: this orange curve. 80 of 81 users pass.
