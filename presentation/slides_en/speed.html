APPENDIX · SPEED ADAPTS TO THE USER

The more weight the user takes off, the faster the seat rises

v = k × (push limit − seat force), clamped between 0 and max speed

  • User sits back: seat force goes over the limit, speed drops to 0; never reverses
  • Speeds up only if the unloaded force shows up on the footplate; hanging on the bar limits speed
  • Per user: push limit 0.5–0.6 × body weight, max speed 1.5–3 cm/s
  • 16 scenarios simulated on the seat path, all end safe (all in appendix); typical user off the seat at 0.57 m within 7 s
How do we set the lift speed? We use one rule: speed equals k times the push limit minus the force the seat measures, kept between zero and the maximum speed. The more weight the user takes off, the faster the seat rises. If the user sits back, the speed goes to zero, and the seat never moves back. The unloaded force must also show up on the footplate before the seat speeds up, so leaning back onto the mattress does not lift the seat. The seat tilts, so the controller uses the tilt angle from the screw encoder to get the vertical force. If the user hangs on the grab bar, speed is limited. On the right are three of 16 simulated scenarios. A typical user leaves the seat at 0.57 metres in about 7 seconds. If the user faints and lets go, the seat stops and holds them, alerts and calls family after 17 seconds, and does not lower by itself. With a power loss, the brake holds, and holding “Down” lowers it slowly on battery.
